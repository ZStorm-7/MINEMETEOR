# Known Minecraft wiki hosts (all verified working; use them as the wiki="..." argument of search_wiki / get_wiki_page)
- minecraft.wiki = official vanilla wiki (default). minecraft.fandom.com = the Fandom Minecraft wiki (search_minecraft checks both).
- lifesteal.fandom.com (Lifesteal SMP), dreamsmp.fandom.com (Dream SMP), bedwars.fandom.com
- hypixel.fandom.com (Hypixel), hypixel-skyblock.fandom.com (SkyBlock)
- minecraftdungeons.fandom.com, minecraft-legends.fandom.com, minecraft-earth.fandom.com
- ftb.fandom.com (Feed The Beast modpacks), create.fandom.com (Create mod), wynncraft.wiki.gg (Wynncraft)
- Any other community: try <name>.fandom.com or <name>.wiki.gg; if a host does not exist, say so instead of guessing.
