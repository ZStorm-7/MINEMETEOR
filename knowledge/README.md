# Teach FINDCRAFTER

Every `.md` or `.txt` file in this folder (except this README) is added to FindCrafter's brain on every question.
No code, no restart needed - just save the file.

Good things to teach it:
- Your own server / SMP: IP, rules, seasons, plugins, staff, lore, Discord.
- Community facts the wikis don't have (strategies, tier lists, meta).
- Corrections: "Actually, X works like Y in 1.21".

Tips: short bullet points beat essays. Put dates on things that change. Keep the total under ~30,000 characters.
- Example: see example-server.md.disabled, rename it to .md to switch it on.
